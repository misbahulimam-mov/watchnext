# WatchNext

**Never Wonder What to Watch.**

WatchNext is a modern discovery platform for movies, TV shows, and books. Find personalized recommendations, explore trending titles and hidden gems, filter by genre and mood, and discover your next favorite story.

## Current build
- Responsive cinematic dark UI
- Movie, TV show and book categories
- Search and recommendation filtering
- Trending and hidden-gem sections
- Detail modal for every title
- Light/dark theme toggle
- Sample data, ready for real APIs

## Roadmap
Real title APIs, accounts, watchlists, richer recommendation logic, and personalized profiles.

> Never put private API keys in this public repository.
